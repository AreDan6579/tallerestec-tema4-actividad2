# TalleresTEC · Tema 4 Actividad 2

Desde la raíz del proyecto, conecta el teléfono Android y ejecuta:

```powershell
flutter pub get
flutter devices
flutter run -d "ID_ANDROID"
```

En **Preferencias de TalleresTEC**, toca el icono de cámara para abrir **Evidencia fotográfica**. Usa **Tomar foto** o **Elegir imagen** y revisa el origen y el nombre debajo de la vista previa. **Quitar imagen** vuelve a la portada. Con **Atrás** regresas a Preferencias.

`flutter test` verifica los estados de la pantalla y las pruebas de notas y preferencias. Las fotos de prueba son `coffee.png` y `coins.png` de [scikit-image](https://scikit-image.org/docs/stable/api/skimage.data.html).
